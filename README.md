# ОТТС Downloader Pro

**ОТТС Downloader Pro** — это десктопное приложение на Python с графическим интерфейсом (Tkinter) для автоматизированного сбора данных из реестра Одобрения типа транспортного средства (ОТТС) с официального портала (gost.ru / rst.gov.ru).

Скрипт решает рутинные задачи по выгрузке огромных массивов данных: от скачивания всего каталога до извлечения специфических PDF-файлов и формирования удобной Excel-таблицы с гиперссылками.

Скрипт записывает данные из страницы каждого найденного ОТТС (техническое описание ТС) и скачивает приложенные к нему pdf (ОТТС) с техническими характеристиками ТС.

Сделан на основе открытых данных для локального хранения и удобного поиска по ним.

## 🚀 Возможности

### Фаза 1: Скачивание каталога
* Постраничный обход и сохранение всего реестра в локальные JSON-файлы.
* Поддержка "умного" кэширования: если страница уже скачана, запрос к серверу не делается.
* Автоматическая миграция данных из старых структур папок.
* Защита от обрывов связи и HTTP 429 (Too Many Requests) с автоматическим ожиданием.

### Фаза 2: Обработка года и скачивание PDF
* Фильтрация документов по году регистрации (или обработка всего массива).
* Извлечение всех ключевых полей: изготовитель, VIN, эко-класс, двигатель, шасси и т.д.
* **Умный поиск PDF:** если вложения нет в карточке каталога, скрипт автоматически переходит на страницу документа и извлекает UUID файла.
* Генерация форматированного **XLSX-отчета** с гиперссылками на локальные PDF-файлы и на карточку документа на сайте.

### Интерфейс и надежность
* Удобный GUI с прогресс-барами, статистикой и окном логов.
* Сохранение прогресса (`processed_ids.json`): если свет или интернет отключится, при следующем запуске скрипт продолжит с места остановки, а не начнет сначала.
* Возможность постановки задачи на паузу/остановку.
* Переиспользование уже скачанных PDF-файлов (экономия трафика и места на сервере).

## 📋 Требования

* Python 3.8+
* Библиотеки: `requests`, `openpyxl`
