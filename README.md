# ОТТС Downloader

**ОТТС Downloader** — это десктопное приложение на Python с графическим интерфейсом (Tkinter) для автоматизированного сбора данных из реестра Одобрения типа транспортного средства (ОТТС) с официального портала (gost.ru / rst.gov.ru).

Скрипт решает рутинные задачи по выгрузке огромных массивов данных: от скачивания всего каталога до извлечения специфических PDF-файлов и формирования удобной Excel-таблицы с гиперссылками.

Скрипт записывает данные из страницы каждого найденного ОТТС (техническое описание ТС) и скачивает приложенные к нему pdf (ОТТС) с техническими характеристиками ТС.

Сделан на основе открытых данных для локального хранения и удобного поиска по ним.

## 📋 Требования

* Python 3.8+
* Библиотеки: `requests`, `openpyxl`

## ⚙️ Установка и запуск

1. Клонируйте репозиторий или скачайте архив:
   ```bash
   git clone https://github.com/Diolocra/otts-downloader.git
   cd otts-downloader
   pip install requests openpyxl
   python otts_downloader.py
   

## Настройка Session-Cookie, gtn.access.appid и App-Id
* Зайдите на сайт gost.ru
* Откройте инструменты разработчика (F12) -> вкладка Network (Сеть).
* Откройте вкладку «Заголовки» (Headers) и пролистайте вниз до раздела «Заголовки запроса» (Request Headers).
* Скопируйте полные значения полей gtn.access.appid и App-Id (включая все символы), вставьте их в исходный код.
* Найдите любой запрос к API (например, libraries/search) и скопируйте значение куки session-cookie из заголовков запроса.
* Вставьте скопированное значение в поле Session Cookie в интерфейсе скрипта и нажмите 💾 Сохранить.
